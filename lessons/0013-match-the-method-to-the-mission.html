Lesson 13 · Phase 3: Retrieval

Match the Method to the Mission

From Dr. Justin Sung · "Learn to Learn" & "13 Years of No BS Study Advice"

Retrieval isn't "do it more" — it's method × frequency, matched to how you'll actually use the knowledge. Your "northern star" is the way you'll be tested or use it: a multiple-choice exam, a client interview, writing code from memory. Ask first: how am I going to be tested on this? how do I need to use my knowledge? Then test yourself that same way.

Method: match to the real task

How you'll use itTest yourself withWhy
Recognize facts (MCQ)Recognition — flashcards, multiple choiceWeakest method, but matches a weak test
Recall with context (fill-in-the-blank)Cued recallMedium — the sentence gives context
Generate and manipulate (solve, explain, code from memory)Free recall (generative)Strongest — you generate and manipulate the knowledge

Don't test low when you'll be examined high

If you only test at a low level (flashcards, single facts) when you'll be examined at a higher level — interconnected, complex application — you'll struggle on exactly the complicated questions. Match the test to the task.

Frequency: start with 1-day → 1-week → 1-month

Then assess retention: dropping too fast → move reviews closer; still strong → spread them out. Each top-up slows decay for that item.

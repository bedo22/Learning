# MISSION.md Format

One short document. Keep it human and specific. Update it when the mission evolves (record the change in `learning-records/`).

## Sections
- **Why**: The underlying reason for learning this topic. Grounds every lesson.
- **Goals**: Concrete outcomes the user wants.
- **Domains**: Where the skill will be applied (keeps examples and interleaving grounded).
- **Success looks like**: What "done" means for the user.
- **Constraints / preferences**: Anything that shapes how we teach (time, tools, preferences from `NOTES.md`).

## Rules
- If the mission is unclear, ask before teaching.
- Confirm with the user before changing the mission. Record the change in a learning record.

# Source digest — Immordino-Yang et al., 2012 (rest is not idleness)

> "Rest Is Not Idleness: Implications of the Brain's Default Mode for Human

## What the doc(s) claim from this source

- rest-and-recovery claims: "Research labels quiet time 'anything-but-idle' — it's where meaning-making and self-reflection happen (Immordino-Yang et al., 2012)."

## Key findings (one line each, with supporting quote)

- **Resting wakefulness is productive for internal mental work, not wasted** — the brain's default mode activates during rest and is important for internally focused processing and for skills like reading comprehension and divergent thinking.
- **"Rest is not idleness" is literal** — the doc's title phrase; quiet rest supports meaning-making and self-reflection rather than being empty downtime.

## Key quotes (with locations)

> "when people wakefully rest ... they engage a so-called default mode (DM) of neural processing that is relatively suppressed when attention is focused on the outside world" — abstract
> "Accruing evidence suggests that DM brain systems activated during rest are also important for active, internally focused psychosocial mental processing" — abstract

## Notes / caveats

- Mostly a conceptual/review + educational-implications argument, not a recovery-biology experiment.
- The "meaning-making / self-reflection" framing is the doc's use; it sits beside RRNA (rest can be negative for some) — both are true, the doc reconciles them in the disputed box.
- **Does NOT support:** that all rest is automatically beneficial — the same internally focused state can be reflection *or* rumination.

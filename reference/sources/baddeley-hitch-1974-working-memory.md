## Key findings (one line each, with supporting quote)

- **Working memory has multiple components** — not a single short-term store, but a system with at least two slave systems (phonological loop, visuospatial sketchpad) controlled by a central executive.
- **The phonological loop handles verbal/acoustic information** — it's responsible for the word-length effect and the phonological similarity effect.
- **The central executive is the attentional controller** — it coordinates the slave systems and manages attention, switching, and inhibition.
- **Capacity is limited but structured** — each component has its own capacity constraints, and the total system is more than a simple slot machine.

## Key quotes (with locations)

> "Working memory is assumed to be a limited-capacity system for temporary storage and manipulation of information for complex tasks such as comprehension, learning, and reasoning." — the core definition

## Notes / caveats

- The model has been extended since 1974: Baddeley added the episodic buffer in 2000, making it a four-component model.
- The model is primarily based on verbal/visuospatial tasks; its applicability to other domains (e.g., mathematical reasoning) is debated.
- **Does NOT support:** that working memory capacity is fixed and unchangeable — training can improve performance on near-transfer tasks (though far transfer is limited, per Syed et al., 2024).

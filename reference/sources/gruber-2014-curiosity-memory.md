## Key findings (one line each, with supporting quote)

- **Curiosity enhances memory** — when people are in a state of curiosity (e.g., eager to learn the answer to a trivia question), they remember not only the answer but also incidental information encountered during the curious state.
- **The dopaminergic circuit is involved** — the effect involves the brain's dopamine system, particularly the ventral tegmental area and its projections to the hippocampus.
- **Curiosity creates a "gateway" for learning** — the curious state primes the hippocampus for encoding, making the brain more receptive to new information.

## Key quotes (with locations)

> "States of curiosity enhanced hippocampus-dependent learning, even for incidental information that was not the target of curiosity." — the key finding

## Notes / caveats

- This is a neuroimaging study (fMRI) with a relatively small sample (n=19). The behavioral effects are robust but the neural mechanisms should be interpreted cautiously.
- The effect was specific to high-curiosity states — moderate curiosity did not produce the same memory enhancement.
- **Does NOT support:** that curiosity alone is sufficient for learning (you still need to attend and process the material), or that the effect works for all types of content.

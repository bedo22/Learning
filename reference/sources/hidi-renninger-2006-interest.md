## Key findings (one line each, with supporting quote)

- **Interest develops through four phases** — from triggered situational interest (Phase 1) → maintained situational interest (Phase 2) → emerging individual interest (Phase 3) → well-developed individual interest (Phase 4).
- **Phases are cumulative, not exclusive** — each phase builds on the previous one, and a person can be in different phases for different topics simultaneously.
- **Knowledge and value judgments grow together** — as interest develops, both knowledge and the value placed on the activity increase, creating a self-reinforcing cycle.

## Key quotes (with locations)

> "Interest is a psychological state that develops in four phases, each with its own characteristics." — the model's core

> "Individual interest is a self-sustained orientation toward re-engagement with a particular topic over time." — on mature interest

## Notes / caveats

- The model is widely cited but the phases are somewhat fuzzy — the boundaries between phases are not always sharp.
- The model overlaps with but is distinct from self-determination theory (SDT). SDT explains *why* activities become intrinsically motivated; the four-phase model explains *how* interest develops over time.
- **Does NOT support:** that all interest must follow this exact sequence, or that triggered situational interest is always a good starting point.

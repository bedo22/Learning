# Source digest — Raichle et al., 2001 (default mode network)

> "A Default Mode of Brain Function" — the foundational Default Mode Network
> (DMN) paper. Cited in rest-and-recovery as the resting-state the brain drops
> into during "doing nothing."

## Identity

- **Full citation:** Raichle, M. E., MacLeod, A. M., Snyder, A. Z., Powers, W. J., Gusnard, D. A., & Shulman, G. L. (2001). A default mode of brain function. *Proceedings of the National Academy of Sciences*, 98(2), 676–682.
- **DOI:** 10.1073/pnas.98.2.676
- **Verified link:** https://doi.org/10.1073/pnas.98.2.676
- **Open-access link:** https://www.pnas.org/doi/10.1073/pnas.98.2.676

## What the doc(s) claim from this source

- rest-and-recovery claims: "Sitting with no input, no tasks — just sitting — switches your brain into its Default Mode Network (Raichle et al., 2001): the resting state where the brain actively generates internally — reflecting, remembering, planning, comparing."

## Key findings (one line each, with supporting quote)

- **The resting brain has an active "default mode," not an empty one** — a baseline state (identified via oxygen extraction fraction) that is engaged during quiet rest and suppressed when attention turns to a task.
- **"Doing nothing" is self-referential processing, not an off switch** — the doc's "doing nothing is an active mental state" point rests on this baseline being a real, structured brain activity.
- **The DMN supports the internal focus of recovery/rest** — resting-state activity is the physiology behind why "rest" is not a neutral empty pause.

## Key quotes (with locations)

> "we identify a baseline state of the normal adult human brain ... remarkably uniform in the awake but resting state (e.g., lying quietly with eyes closed)" — abstract

## Notes / caveats

- The paper's baseline-state claim interacts with ongoing debate over exactly which regions form the "DMN" and how to interpret rest; the doc treats it as shorthand ("do not trust as anatomy," see the doc's What-to-trust note).
- The DMN is neither purely positive nor negative; later work (e.g., rumination/mind-wandering) builds on but does not replace this.
- **Does NOT support:** that resting-state activity is pleasure/recovery; it is a neural state that can be restorative *or* restless (the doc's disputed box makes this negative-space point).

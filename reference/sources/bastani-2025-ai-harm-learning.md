## Key findings (one line each, with supporting quote)

- **Unguarded GPT access harms learning while boosting performance-in-the-moment** — in a field experiment (~1000 high-school math students), GPT-4 access improved immediate performance (48% improvement) but, in the unguarded "base" condition, significantly reduced performance on the following exam when GPT was withdrawn — i.e., it *harmed* real learning.
- **Tool design is decisive** — a "GPT Tutor" with prompts designed to safeguard learning avoided the harm; the raw ChatGPT-interface tutor did not.
- **It feels productive while degrading learning** — the doc's "wanting without liking": students felt great doing the task, yet learned less.

## Key quotes (with locations)

> "study this question via a field experiment where we provide nearly a thousand high school math students with access to generative AI tutors" — abstract
> "having GPT-4 access while solving problems significantly improves performance ... [but] unguarded AI access ... harmed learning" — abstract summary

## Notes / caveats

- The polished headline is about the *unguarded* interface; the guarded-tutor result improved/got performance — the doc quotes only the "can harm learning" half (correctly, for its study-error point). The doc's AI-doc sibling covers the guarded/normal contrast.
- Field setting, single math topic; the doc treats it as the "harm" data point in the acclaimed pair of RCTs (vs Kestin).
- There was a published critique of the study design (Tan & Rajaratnam, SSRN 10.2139/ssrn.4898213) — worth noting if precision is needed, but the learning-cost direction is the doc's point.
- **Does NOT support:** that all AI study tools harm learning — the doc explicitly pairs it with Kestin's gain to say "design decides," confirming the divisions are findings.

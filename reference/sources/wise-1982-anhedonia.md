## What the doc(s) claim from this source

- wanting-vs-liking claims: Wise's anhedonia hypothesis — dopamine blockade attenuates reward (the "dopamine = pleasure" position that Berridge later corrected to "dopamine = wanting").

## Key findings (one line each, with supporting quote)

- **Dopamine blockade reduces reward-seeking behavior** — neuroleptics (dopamine antagonists) reduce operant responding, interpreted as reduced pleasure (anhedonia).
- **This is the "dopamine = pleasure" position** — the doc's wanting-vs-liking doc explains that Berridge's work corrected this: dopamine blockade reduces *wanting*, not necessarily liking.

## Key quotes (with locations)

> "the anhedonia hypothesis" — title (dopamine blockade = reduced pleasure)

## Notes / caveats

- Historically important; the doc uses it as the position that later research refined — the "dopamine = pleasure" view vs Berridge's "dopamine = wanting."
- The doc's wanting-vs-liking thesis directly engages this: anhedonia vs incentive-salience interpretations.
- **Does NOT support:** the modern wanting/liking distinction — it predates and is corrected by it.

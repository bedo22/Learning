## Key findings (one line each, with supporting quote)

- **Irrelevant speech disrupts visual-verbal serial recall** — changing-state speech interferes with remembering sequences of letters, words, and other verbal stimuli.
- **Spatial serial recall is spared** — the same speech does not disrupt memory for spatial sequences (e.g., remembering locations in order).
- **The phonological loop is the mechanism** — the effect is specific to verbal working memory, confirming that irrelevant sound competes for resources in the phonological loop.

## Key quotes (with locations)

> "Changing-state speech disrupted visual-verbal serial recall but had no effect on spatial serial recall." — the key finding

## Notes / caveats

- This study adds nuance to the irrelevant-sound literature by showing the effect is modality-specific.
- The findings support Baddeley's phonological loop model as the mechanism.
- **Does NOT support:** that all memory is equally disrupted by noise (spatial memory is spared), or that the irrelevant-sound effect is universal across all memory types.

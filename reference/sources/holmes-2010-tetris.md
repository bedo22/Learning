## Key findings (one line each, with supporting quote)

- **Tetris after trauma reduces intrusive memories** — a visuospatial task competes with trauma-memory consolidation, reducing flashbacks.
- **Engagement can be therapeutic, not just escapist** — the doc's screen context: a game can reduce intrusive memories (distinct from numbing).

## Key quotes (with locations)

## Notes / caveats

- The effect is specific to the visuospatial-interference mechanism (playing *after* re-exposure), not general gaming.
- The doc cites it in the screen/engagement context — an example where engagement helps (vs wanting-feed numbing).
- **Does NOT support:** that gaming generally reduces trauma/memory — the mechanism is task-specific interference.

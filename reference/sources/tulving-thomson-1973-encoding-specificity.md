## Key findings (one line each, with supporting quote)

- **Retrieval depends on encoding-retrieval overlap** — memory is not a fixed trace that is "accessed" by a cue; rather, the cue must overlap with what was encoded at study for successful retrieval.
- **Encoding specificity principle** — "Remembering is a rejoining of what has been stored and what the retrieval cues can make available." Specific cues that match the encoding context outperform general cues.
- **Transfer-appropriate processing** — processing that is appropriate at encoding (e.g., rhyming) is more effective than processing that is appropriate at test (e.g., semantic) if the test cue matches the encoding process.

## Key quotes (with locations)

> "What a person can retrieve is governed by the relationship between what has been stored and what retrieval cues can make available." — the core principle

> "Encoding specificity" — the name for the principle that successful retrieval requires overlap between the encoding and retrieval representations.

## Notes / caveats

- This paper introduced the *encoding specificity principle*, which is foundational to modern memory research.
- The principle explains why the same word can be easy or hard to remember depending on the cues provided at test.
- **Does NOT support:** that memory is always cue-dependent in the way that would make it "unfair" — the shelf's application (match retrieval cues to how you'll use the knowledge) is a practical extension of the principle.

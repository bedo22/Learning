## What the doc(s) claim from this source

- rest-and-recovery claims (Sleep section): sleep does the heavier consolidation work —
  deep/slow-wave sleep replays and strengthens studied material; this review is the current
  state of the field behind that claim.

## Key findings (one line each, with supporting quote)

- **Sleep is a brain state for memory formation** — consolidation during sleep is an active,
  organized process, not passive protection from interference.
- **Stage-specific contributions** — slow-wave sleep drives hippocampo-neocortical replay of
  declarative material; REM contributes emotional and procedural aspects.
- **Comprehensive coverage** — as a Physiological Reviews flagship review (~120 pages) it is
  the authoritative current synthesis of the sleep–memory literature.

## Key quotes (with locations)

> "Sleep's contribution to memory formation" — title framing.

## Notes / caveats

- Review article: claims represent field consensus it synthesizes; specific effect sizes
  should be traced to primary studies within.
- **Does NOT support:** that more sleep uniformly equals more learning beyond sufficiency,
  or that wakeful rest substitutes for sleep (complementary mechanisms — see Weng 2025).

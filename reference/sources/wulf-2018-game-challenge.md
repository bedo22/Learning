## Key findings (one line each, with supporting quote)

- **Challenge experience relates to media-induced recovery** — game challenge (difficulty) must match the player; mismatched challenge fails to recover.
- **Too hard = stress, too easy = boredom** — the doc's flow-style claim: recovery needs the right difficulty band.

## Notes / caveats

- The doc cites it as "2018" — online-first 2018, print issue 2019; both refer to the same article.
- The difficulty-matching claim is flow-consistent (Csikszentmihalyi); the doc pairs them.

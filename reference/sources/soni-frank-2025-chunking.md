## Key findings (one line each, with supporting quote)

- **Chunking strategies can be learned** — computational models show that learning to group items into meaningful chunks effectively expands working memory capacity.
- **Capacity is partly computational, not just anatomical** — the ~4 chunk limit is not a hard ceiling; learned strategies can increase the effective number of items maintained.
- **The model reconciles Miller and Cowan** — the ~7 estimate reflects chunking-enhanced capacity, while ~4 reflects raw capacity; both are valid under different conditions.

## Key quotes (with locations)

> "Effective working memory capacity is not fixed at 4 chunks but can be expanded through learned chunking strategies." — the key finding

## Notes / caveats

- This is a computational modeling study, not a behavioral experiment. The findings suggest a mechanism but don't directly prove it in humans.
- The model is consistent with behavioral evidence from memory athletes and chunking training studies.
- **Does NOT support:** that working memory capacity is unlimited (there is still a ceiling), or that chunking eliminates the capacity limit (it expands it, doesn't remove it).

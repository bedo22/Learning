## Key findings (one line each, with supporting quote)

- **The ego-depletion effect failed to replicate** — the preregistered multilab study found d ≈ 0.04, near zero.
- **Depletion-based explanations are contested** — the doc cites this as the honest caveat: "my willpower ran out" is not a well-supported mechanism.

## Key quotes (with locations)

## Notes / caveats

- The multilab replication was followed by methodological debate (R-Core protocol, later meta-analyses) — the null remains the headline.
- The doc cites it as the *caveat* on depletion-based explanations — used honestly.
- **Does NOT support:** that ego depletion is real; the doc uses it to avoid overclaiming willpower-as-resource.

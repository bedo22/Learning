## Key findings (one line each, with supporting quote)

- **Deeper processing produces better memory** — processing that engages meaning (semantic, elaborative) produces stronger memory traces than shallow processing (structural, phonemic).
- **Depth is a continuum, not a binary** — processing depth ranges from superficial (e.g., "is this word in uppercase?") to deep (e.g., "does this word fit in this sentence?").
- **Durability depends on depth** — traces produced by deep processing are more durable and resist decay and interference.

## Key quotes (with locations)

> "A given item may be processed at a number of levels from superficial to deep, and this degree of processing will determine its subsequent remembering." — the core claim

> "The memory trace is considered to be a by-product of the processing operations, and the persistence of the trace is a function of depth of processing." — on trace durability

## Notes / caveats

- This is a theoretical framework paper, not an empirical study.
- The framework has been enormously influential but also critiqued: "depth" is hard to measure independently of performance, and some evidence suggests that distinctiveness matters more than depth per se (e.g., the distinctiveness effect).
- **Does NOT support:** that all deep processing is equally effective, or that depth is the *only* factor in memory quality (distinctiveness, distinctiveness, and organization also matter).

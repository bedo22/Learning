## What the doc(s) claim from this source

- rest-and-recovery claims: "During deep (slow-wave) sleep the brain replays and strengthens the declarative material you studied; REM sleep handles emotional and procedural learning. Missing either stage costs you the learning you already did — Diekelmann & Born's (2010) review ... unambiguous: sleep is not downtime from learning, it is a core part of the learning process."

## Key findings (one line each, with supporting quote)

- **Sleep consolidates newly learned information** — sleep is a state that optimizes consolidation, promoting both quantitative and qualitative changes to memory.
- **Slow-wave sleep and REM do complementary consolidation work** — SWS (with slow oscillations, spindles, ripples) re-activates and redistributes hippocampus-dependent memories to neocortex; REM supports synaptic/cortical consolidation.
- **Sleep is a core part of learning, not downtime** — the doc's exact framing ("sleep is not downtime from learning, it is a core part of the learning process").

## Key quotes (with locations)

> "Sleep has been identified as a state that optimizes the consolidation of newly acquired information in memory ... During SWS, slow oscillations, spindles and ripples ... coordinate the re-activation and redistribution of hippocampus-dependent memories to neocortical sites, whereas during REM sleep, local increases in plasticity-related immediate-early gene activity ... might favour the subsequent synaptic consolidation of memories in the cortex" — abstract

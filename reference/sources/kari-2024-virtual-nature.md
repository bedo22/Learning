## Notes / caveats

- Experimental comparison of technologies; effect sizes vary by delivery.
- The doc uses it as evidence that virtual nature is a fallback for real nature (relevant to indoor/screen recovery).
- **Does NOT support:** that virtual nature equals real nature (ART predicts real nature is stronger); it's the fallback case.

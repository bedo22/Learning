## Key findings (one line each, with supporting quote)

- **Judgments of learning rely on cue utilization, not direct memory access** — people don't "check" their memory; they infer how well they've learned from cues like processing fluency, familiarity, and retrieval ease.
- **The accessibility model** — ease of initial encoding and ease of retrieval serve as cues that influence JOLs, independent of actual memory strength.
- **Fluency is a double-edged sword** — conditions that make encoding feel easy (e.g., rereading) inflate JOLs but don't improve actual retention. Conditions that make encoding feel hard (e.g., spacing, testing) deflate JOLs but improve retention.

## Key quotes (with locations)

> "People rely on cues to infer how well they have learned, rather than directly accessing memory strength." — the core model

## Notes / caveats

- This is a theoretical framework paper with extensive empirical support.
- The cue-utilization model explains why desirable difficulties feel ineffective — they reduce fluency, which people use as a proxy for learning.
- **Does NOT support:** that all JOLs are inaccurate (they're calibrated in some conditions), or that fluency is always misleading (it's a valid cue for some forms of knowledge).

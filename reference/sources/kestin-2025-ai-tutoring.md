## Key findings (one line each, with supporting quote)

- **A well-designed AI tutor outperforms active-learning class sessions** — in an RCT, students learned significantly more in less time with the AI tutor than in the in-class active learning condition.
- **Students felt more engaged and motivated with the AI tutor** — the "feels great" side notes; the doc reads this as design-dependent, not automatic.
- **The tutor mirrors in-class pedagogy** — the AI tutor was built on the same pedagogical best practices, not a raw answer machine (contrast with Bastani's unguarded "base").

## Key quotes (with locations)

> "We find that students learn significantly more in less time when using the AI tutor, compared with the in-class active learning. They also feel more engaged and more motivated" — abstract

## Notes / caveats

- The "gain" depends on tutor design (safeguards/pedagogy); the doc pairs it with Bastani's harm to make the "design decides, not AI-in-general" point.
- In-class active learning was the active control, so the comparison is against good teaching, not no teaching.
- **Does NOT support:** that any AI answers learn — the doc uses this to say tool design, not mere access, is what produces liking-based learning.

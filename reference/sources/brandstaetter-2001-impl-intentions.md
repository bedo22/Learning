## Key findings (one line each, with supporting quote)

- **If-then plans initiate action efficiently** — implementation intentions automate the response, reducing deliberation.
- **They work under cognitive load** — the doc's "tired-PFC moment": the cue fires even when conscious control is depleted.

## Key quotes (with locations)

## Notes / caveats

- The effect is reliable for *initiation*; the doc uses it for the scripted-start (productivity-systems cross-link).
- The doc's "you can't plan play" guardrail is the companion: scripting the *start* is fine; scripting play itself isn't play.
- **Does NOT support:** that if-then plans preserve voluntary play — the doc's dark twin.

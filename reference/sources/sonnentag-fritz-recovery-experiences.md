## Key findings (one line each, with supporting quote)

- **Recovery is an experience, not an activity** — the REQ measures four experiences; the same activity can recover or not depending on the experience it produces.
- **The four experiences: detachment, relaxation, mastery, control** — the doc's recovery score is the mean of these four.
- **Mastery (in REQ) = challenge that builds competence, not expertise** — the doc's "play is mastery minus the outcome" uses this technical sense.

## Key quotes (with locations)

> "psychological detachment... relaxation... mastery... control" — the four REQ dimensions (scale definition, p. 206)

## Notes / caveats

- The REQ is a self-report measure; the strict list's 0–10 scores are an *application* of the constructs (behavioral-activation style), not the original Likert instrument.
- The doc's recovery score mean(D·R·M·C) is an adaptation; the original REQ treats dimensions separately (a person can detach without mastering).
- **Does NOT support:** that any given activity *guarantees* a recovery experience, or that recovery requires all four at once — the doc's strict list already scores them separately.

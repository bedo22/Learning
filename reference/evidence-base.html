Every claim in this shelf traces back to a verified source. This doc explains the trust tiers, coverage, and verification pipeline that make "evidence-grounded" more than a label.

The trust tiers — what each source level means

Not all journals are equal. We categorize every cited paper into five tiers based on how rigorous and selective the publication venue is. 65% of the shelf's sources are Tier 1–2 — the most rigorous peer-reviewed journals in their fields.

Tier Description Count % What it means
Tier 1 Top field journals — Psychological Science, Nature, Science, JPSP, American Psychologist, Psychological Review, PNAS, Neuron, eLife 45 31% Most selective, highest rejection rates, most cited in the field. If a finding is here, it survived the toughest peer review.
Tier 2 Strong specialty journals — JEP:LMC, JEP:HPP, Ed Psych Review, BBS, Annual Review, Applied Psych, Brain Research Reviews 48 34% Respected in their subfield, rigorous review, widely cited. Tier 2 journals are where most specialized findings live.
Tier 3 Open-access / newer — Frontiers in Psychology, PLOS ONE, Scientific Reports, MDPI Behavioral Sciences 11 8% Legitimate peer-reviewed journals, but less selective. Used here as supplementary evidence — they support claims already backed by Tier 1–2 sources.
Tier 4 Books, chapters, preprints — MIT Press, Academic Press, Worth, Psychology Press, OSF 38 27% Classic books and book chapters that are foundational to their fields (Bjork, Baddeley, Miller, Ericsson, Huizinga). These are widely cited and accepted even though they aren't journal articles.
Tier 5 Chinese-language journals 1 1% Non-English journals. Used sparingly — cite with caution and verify the DOI independently.

What this means for you

When a shelf doc makes a claim and cites a source, you can check the tier to gauge how robust the evidence is. A claim backed by Tier 1–2 sources has survived rigorous peer review. A claim backed by Tier 4 (a book chapter) comes from a canonical text that the field treats as authoritative. A claim backed only by Tier 3 should be read as "suggestive but not definitive."

The shelf is conservative by design: contested mechanisms are labeled as such, single small studies are flagged, and claims never exceed what the cited source supports. The Does NOT support section in every source digest defines the boundary — what a future reader must not use that paper to claim.

How we verify — the pipeline

Every DOI in the shelf is machine-verified before shipping. Here's the process:

  1. Crossref API check — each DOI is queried against api.crossref.org/works/{DOI}. A 200 response means the DOI is registered and active. A 404 means the DOI is wrong or unregistered.
  2. Cache-first verification — results are stored in .link-cache.json. Re-runs on unchanged docs make zero network requests. The steady state is cache-only.
  3. Rate limiting — at most 1 request/second with random jitter. Exponential backoff on 429/503. Anti-bot by design.
  4. Scan both docs and digests — a dead DOI in a source digest fails the run just like a dead link in an HTML doc.

Run it yourself

From the reference/ directory: 

python3 scripts/verify-links.py          # cache-first (normal)
python3 scripts/verify-links.py --force  # re-check everything
python3 scripts/verify-links.py --json   # machine-readable report

Exit code 0 = all links pass. Exit code 1 = one or more failures. The report lists every link with its status and the reason for failure.

What a source digest contains

Every source digest in reference/sources/ follows the same template. Each field is load-bearing for the verification pipeline:

Field What it tells you
Identity Full citation, DOI, verified link, open-access link (if any).
What the doc(s) claim Exactly what each shelf doc says this paper supports. This is the "claim trace" — you can see whether a doc is overclaiming.
Key findings One-line answers the paper provides, each tied to a supporting quote.
Key quotes Exact quotes with section/page locations. A future agent can read THIS section and answer questions without re-scraping the web.
Notes / caveats What the paper does NOT support. Correlational findings, small samples, contested mechanisms — all flagged here.
Related digests Other papers in the same evidence cluster. Read the cluster, not just one paper.
Verification history When the DOI was last checked and whether it passed.

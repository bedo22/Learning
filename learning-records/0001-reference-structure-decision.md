# 0001 — Reference-doc structure decision

- **Date:** Session 2
- **Topic:** How to split Justin Sung's transcripts into reference docs without repetition

## Context
Transcript #2 ("Learn to Learn", 109 min) is the spine of the whole course — four parts: myths, learning system, orders of learning, self-management. It overlaps conceptually with the already-built Bloom reference (effort hypothesis, knowledge decay) and with later transcripts (#5 rest, #6 productivity, #7 goals will touch self-management).

## Key decision
Split the 109-min overview into **four** reference docs, each a tight printable "raw unit," and keep a **single shared glossary** as the canonical term store:
- `learning-myths.html` (Part 1)
- `learning-system.html` (Part 2 — encoding/retrieval + memory mechanics)
- `orders-of-learning.html` (Part 3 — Justin Sung's 2-level model; cross-linked to Bloom's 6 levels, not a duplicate)
- `self-management.html` (Part 4 — time, task/Eisenhower, focus)

To avoid repetition: concepts already defined elsewhere (misinterpreted effort hypothesis, knowledge decay/forgetting curve) are **cross-linked, not re-explained**. The glossary is **extended** with new terms only. Self-management is one doc now so transcripts #5/#6/#7 can **extend** it later rather than spawn duplicates.

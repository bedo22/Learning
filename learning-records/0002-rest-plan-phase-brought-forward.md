# 0002 — Rest & Plan Phase Brought Forward

## Date
2026-07-31

## Topic
Lesson plan restructuring — rest & planning lessons advanced to Phase 1

## Context
The user reported struggling with resting — specifically: resting between focus sessions, end-of-day resting, and planning rest between tasks. The original plan (0001) placed rest (L15) and the weekly ritual (L14) in Phase 4 (Integrate), which was too late. The user's immediate need puts rest in their zone of proximal development right now.

## Key insight / decision
Restructured the lesson plan from 16 lessons / 5 phases to 18 lessons / 6 phases:
- **New Phase 1: Rest & Plan (4 lessons)** inserted between Reframe and Enablers — not in Sung's original pillar order, but prioritized because the user's zone of proximal development demands it.
- 2 genuinely new lessons created: L05 (The recovery break — rest between sessions) and L06 (Leave work at work — end-of-day transition).
- 2 existing lessons repurposed/moved forward: old L15 (Recover on purpose) → L04 (Real rest vs fake rest), old L14 (The Sunday 30) → L07 (Plan rest, not just work).
- Old Phase 1 (Enablers) → Phase 2, Phase 2 (Retrieval) → Phase 3, Phase 3 (Encoding) → Phase 4, Phase 4 (Integrate) → Phase 5 (now just RAIL).

## Evidence
- User message: "I face trouble In resting... I want to focus on the resting between focus sessions and if there's end of day resting and so on, and planning especially planing the rest between my tasks and so on"
- Teaching philosophy: "Teach the most relevant thing that fits in their zone of proximal development"
- Reference docs: rest-and-recovery.html (four dimensions, soft fascination, recovery paradox, PFC fatigue), productivity-systems.html (scripted actions, flow matching, weekly ritual)

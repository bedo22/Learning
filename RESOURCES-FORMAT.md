# RESOURCES.md Format

A curated list of high-trust resources used to ground teaching. **Never trust parametric knowledge — cite sources.**

## Sections
- **Primary sources**: The main high-trust materials (creator's channel/videos, books). Each entry: title, link, type, one-line note.
- **Underlying research / frameworks**: Academic foundations behind the topic.
- **Communities**: Where the user can test skills in the real world (forums, subreddits, classes).
- **Books / long-form**: Deeper reading.

## Rules
- Prefer primary over secondary sources.
- Add a citation as soon as a resource informs a reference doc or lesson.
- Mark the trust level if uncertain.
- A reference doc or lesson should cite its **primary source** with a `.cite` block.
